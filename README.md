# learning-frontend-base

Working docs for openedx/frontend-app-learning #1905, "Convert Learning to frontend-base" (started 2026-10). Covers epic 1 through its landing on `master`; epics 2 (#2185) and 3 (#2186) get their own efforts. Every decision these files record is embedded in the corresponding upstream issue or PR body; nothing here is linked from the project repo.

- `decisions-1905.md`: the effort-level decision log; stays here, restated into issue bodies as needed
- `plan-<issue>.md`: pre-implementation plan per issue
- `decisions-<issue>.md`: decisions made while implementing a layer, embedded verbatim in its PR
- `manual-testing-<issue>.md`: tutor-local observations per layer
- `issue-body-<n|slug>.md`, `pr-body-<n>.md`: drafts and mirrors of upstream bodies
