# learning-react-query

Working docs for openedx/frontend-app-learning epic #1946, "Convert Learning from redux to Context + react-query" (2026-06 to 2026-10). Every decision these files record is embedded in the corresponding upstream issue or PR body; nothing here is linked from the project repo.

This is not the epic's complete set. The docs were untracked files in the checkout and were only kept from late September on; earlier layers' plans, decision logs and manual-testing records (PR #2021 and before, for instance) survive only as the `<details>` blocks embedded in their PR and issue bodies on GitHub.

- `plan-<issue>.md`: pre-implementation plan per issue
- `decisions-<issue>.md`: settled decision log per layer, embedded verbatim in its PR
- `manual-testing-<issue>.md`: tutor-local observations per layer
- `issue-body-<n|slug>.md`, `pr-body-<n>.md`: drafts and mirrors of upstream bodies
