## What moves

Files port from the legacy `src/` tree to the same relative path under `frontend-base/src/`, with their tests, and get a line each in `frontend-base/manifest.tsv`.

- The progress tab: the tab component, course grade, grade breakdown and grade summary, course completion with its donut chart, certificate status, related links, messages.
- The progress query, its key, API function and normalizer, into the course-home data module that #2189 established. The tab owns the fetch; readers below it read the cache without fetching, as on `master`.
- The exams-data hook the progress tab exposes for plugins. It has no caller inside Learning; it ports as code with the tab, and the pull request records whether the package's index exports it, since under frontend-base the app is a library and a plugin can no longer import it by source path.

## Placeholder slots

The seven progress slots (certificate status, certificate status main body and side panel, course completion, course grade, grade breakdown, related links) keep their files and names and render their default content in a bare fragment, with no plugin-framework import. Props the slots passed to plugins are not passed anywhere; the Slot API port in #2185 restores them.

## Testing

The conventions #2189 set: tests port with their files and reach the page through the exported route array at both progress paths; per-file frontend-base mocks; the HTTP client mocked per file.

## Acceptance

- [ ] Progress renders for a learner with grades, for one without, and for a course with a certificate available; the three certificate states render
- [ ] Staff open `progress/:targetUserId` and see that learner's progress
- [ ] The seven progress slots are placeholder slots rendering their default content
- [ ] The exams-data hook is present; the pull request states whether it is exported from the package index
- [ ] Types, lint and tests of the new package pass; the legacy workflow stays green; `npm run dev` from the package serves progress
- [ ] Manifest lines added for every file moved; the progress directory's coverage compared against the `master` baseline
