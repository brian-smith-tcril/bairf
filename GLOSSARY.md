# Effort glossary

Terms specific to this effort. Repo terms are in bairf's `openedx/repos/frontend-app-learning/GLOSSARY.md`, ecosystem terms in `openedx/GLOSSARY.md`.

- **placeholder**: the epic-1 state of a plugin slot: the slot module keeps its file and name, renders its default content in a bare fragment, and is wired to neither mechanism; a slot with no default content renders nothing.
