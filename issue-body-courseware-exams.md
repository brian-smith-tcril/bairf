## The library already fits

`@edx/frontend-lib-special-exams` 5.x, which `master` already uses, has no frontend-platform, redux or plugin-framework dependency. Its [`SpecialExamsProvider`](https://github.com/openedx/frontend-lib-special-exams/pull/176) takes everything from the host: a config object with camelCase keys, an HTTP client, a logger and a signed-in flag. frontend-base supplies all four, so the host side is a small adapter.

## What moves

Files port from the legacy `src/` tree to the same relative path under `frontend-base/src/`, with their tests, and get a line each in `frontend-base/manifest.tsv`.

- Learning's host provider ([`SpecialExamsProvider.tsx`](https://github.com/openedx/frontend-app-learning/blob/master/src/generic/special-exams/SpecialExamsProvider.tsx)), rewired to frontend-base: `lmsBaseUrl` and `siteName` from site config; `examsBaseUrl`, `supportUrl`, `contactUrl`, `proctoredExamFaqUrl` and `proctoredExamRulesUrl` from Learning's app config under their existing uppercase keys; the authenticated HTTP client, the error logger and the signed-in user from frontend-base's runtime.
- The timer wrapper ([`TabWithTimer.tsx`](https://github.com/openedx/frontend-app-learning/blob/master/src/tab-page/TabWithTimer.tsx)), which mounts the provider and the library's outer exam timer on every course tab; it replaces the pass-through #2189 left.
- In the sequence, the library's `SequenceExamWrapper` around the unit content, with the submitted-timed-exam instructions slot passed as its prop; and in the unit, the exam-access hook ([`useExamAccess.ts`](https://github.com/openedx/frontend-app-learning/blob/master/src/courseware/course/sequence/Unit/hooks/useExamAccess.ts)) that blocks the content iframe until the exam access token is ready. Both replace the stubs #2196 left.
- The test setup's use of the library's `testing` export, the stateful mock of the special-exams backend, so exam tests run off the network as on `master`.

## Local verification

Without `EXAMS_BASE_URL` the library talks to the LMS's `edx_proctoring` endpoints. A real timed exam needs the special-exams feature enabled in the LMS (`ENABLE_SPECIAL_EXAMS`, off by default) and "Enable Timed Exams" on the course. Proctored states are mocked; no third-party proctoring software runs locally.
